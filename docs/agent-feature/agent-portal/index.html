Agent Portal

Guide to agent portal access, capabilities, and limitations.

Portal Access​

Agent Portal URL​

https://moresailing.co.uk/agent

Login Credentials​

Username: Agent's company client email
Password: Configured password

Multi-User Access​

Multiple users from the same agent company can log in.

Shared Access:

  • Same commission rate
  • Same company bookings
  • Same permissions
  • Same restrictions

Agent Capabilities​

What Agents CAN Do​

✅ Login & Authentication

  • Secure login with credentials
  • Session management
  • Password recovery

✅ View Bookings

  • All bookings created by their company
  • Booking details
  • Passenger information
  • Tour details

✅ Booking Information

  • View booking status
  • See passenger overview
  • Check tour details
  • View commission amount

✅ Create New Bookings

  • Browse available tours
  • Start new booking
  • Enter passenger details
  • Select services

Access Restrictions​

What Agents CANNOT Do​

❌ Edit Bookings

  • Cannot modify confirmed bookings
  • Cannot update passenger details
  • Cannot change services
  • Cannot adjust pricing

❌ Cancel Bookings

  • Cannot cancel bookings
  • Cannot request refunds
  • Cannot modify booking status

❌ Modify Passengers

  • Cannot edit passenger information
  • Cannot add/remove passengers after confirmation
  • Cannot update contact details

❌ Make Payments

  • Cannot process payments in system
  • Cannot view payment history
  • Cannot access payment links

❌ Change Services

  • Cannot add/remove add-ons
  • Cannot modify transport
  • Cannot change accommodation
Read-Only Access

Agent access is read-only after booking confirmation. All modifications must be requested through customer support.

Portal Features​

Dashboard​

Agent dashboard shows:

  • 📊 Total bookings
  • 📅 Upcoming tours

Booking List​

Filter Options:

  • By date range
  • By tour
  • By booking status
  • By passenger name

Sort Options:

  • Booking date
  • Departure date
  • Booking number
  • Commission amount

Booking Details View​

Each booking displays:

General Information:

  • Booking number
  • Booking date
  • Tour name
  • Departure date
  • Booking status

Passenger Information:

  • Number of passengers
  • Passenger names
  • Age categories
  • Special requirements

Financial Information:

  • Booking total
  • Commission amount
  • Net payable amount
  • VAT breakdown

Services:

  • Transport details
  • Pickup information
  • Add-ons selected
  • Accommodation type

Session Management​

Login Session​

Session Duration: 24 hours
Auto-logout: After 2 hours of inactivity
Remember Me: Optional (30 days)

Security Features​

✅ Secure HTTPS connection
✅ Password encryption
✅ Session timeout
✅ Login attempt limiting
✅ IP logging (security audit)

Support & Assistance​

For Booking Modifications​

Agents must contact support for:

  • Editing confirmed bookings
  • Cancelling bookings
  • Changing passenger details
  • Modifying services

Contact Methods​

📧 Email: support@moresailing.co.uk
📞 Phone: +44 (0) 20 1234 5678
⏰ Hours: Mon-Fri, 9:00-17:00 GMT

Best Practices​

For Agents​

✅ Before Confirming:

  • Double-check all passenger details
  • Verify contact information
  • Confirm service selections
  • Review commission calculation

✅ After Confirming:

  • Download confirmation email
  • Save booking reference
  • Communicate with customer
  • Track departure date

✅ Regular Checks:

  • Monitor upcoming departures
  • Review commission reports
  • Update customer information
  • Check for system updates

Important Reminders​

Read-Only

Remember, portal access is read-only after booking confirmation. Plan ahead and verify details before confirming.

Customer Communication

You are responsible for all customer communication. The system does not send automated emails to end customers.

Data Accuracy

Ensure all data is accurate before confirmation, as you cannot edit bookings after confirmation.

Booking Without Tour

Create flexible, custom bookings without associating them with a specific tour.

Overview​

The system supports creating bookings independently of pre-configured tours, ideal for:

  • Custom itineraries
  • Ad-hoc bookings
  • Client-specific arrangements
  • Flexible travel packages

Creating a Booking Without Tour​

Steps​

  1. Go to the booking Booking module
  2. Click on create new booking
  3. Select Fit option
  4. Fill in all required filed
  5. Add passengers manually
  6. Click Save

Initial Status​

When created, bookings without tour have these characteristics:

Quote Status
  • Saved under the Tour Quote tab
  • Initial status: Quote
  • All Itinerary tab functionalities available

Key Advantages​

✅ Flexible Passenger Management​

Tour-Based Booking:

  • Passenger count locked

Booking Without Tour:

  • Increase/decrease passengers freely
  • Add passengers anytime
  • No tour configuration restrictions

✅ Full Itinerary Control​

Manually configure every aspect:

  • Add flights with custom PNRs
  • Select any hotels
  • Create custom activities
  • Configure all financial lines independently

✅ Custom Pricing​

Complete pricing control:

  • Set your own markups
  • Apply custom discounts
  • Control profit margins
  • Flexible VAT/tax handling

✅ Automated Calculations​

Full access to financial summary:

  • Real-time cost tracking
  • Profit margin calculations
  • Total price visibility

Confirming the Quote​

Convert quote to confirmed booking when ready.

Steps​

  1. Review all Itinerary tab details
  2. Verify passenger information
  3. Check financial calculations
  4. Ensure all services are added
  5. Click Confirm Quote
  6. Status changes: Quote → Confirmed
  7. Booking moves to confirmed bookings list

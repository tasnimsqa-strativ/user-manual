Hotels Section

Manage all hotel-related information including accommodations, room assignments, and financial data.

Add Hotel (Tour with Attached Hotels)​

Hotels associated with the tour are automatically displayed in the hotel list. To add a hotel manually, click the Add Hotel button, where all available hotels for the tour will be shown.

Steps​

  1. Click Add Hotel
  2. List displays all hotels attached to the tour
  3. Select hotel(s) to add
  4. Confirm selection

Selected hotels will appear in the Hotels section.

Manual Hotel Addition​

Add hotels not attached to the tour.

Steps​

  1. Click Add Line
  2. Enter hotel details manually
  3. Fill required information
  4. Click Save

Attached Hotel Financials​

When selecting a tour-attached hotel:

Automatic Display

Pre-configured financial lines display automatically for tour-attached hotels.

You can:

  • View default pricing
  • Modify if needed
  • Add additional costs

Link Passenger to Hotel​

Assign passengers to specific hotel rooms.

Steps​

  1. Click Link Passenger2
  2. Select passenger(s) for this hotel
  3. click on link segment

Delete option is also available to remove a hotel linkage.

Benefits​

  • Track room assignments
  • Manage passenger accommodations
  • Verify booking requirements
  • Simplify check-in process

Best Practices​

✅ Link all passengers to hotels
✅ Verify room types match passenger count
✅ Check-in/check-out dates match itinerary
✅ Review hotel financial lines for accuracy
✅ Note special requests in remarks
✅ Confirm room availability before booking

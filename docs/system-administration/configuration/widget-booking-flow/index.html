Search Parameters & Booking Flow

Complete guide to widget search parameters and the step-by-step booking process.

Search Parameters Configuration​

In the Configurations → Search Parameters section of the Admin Portal, the options that are enabled are automatically reflected in the Widget. Only the parameters activated by the admin will be available to users as search filters in the widget.

Example Configuration​

In the example shown in the screenshots, the following search parameters are enabled from the Admin Portal:

  • Departure Date
  • Tour Tag
  • Country
  • Passenger Types

Admin Portal:​

As a result, these options appear as search dropdowns in the widget.

Searching for Tours​

Users can select specific criteria from the available search options and click on Search. Based on the selected criteria, the widget displays all matching tours.

Tour Information Display​

For each tour, the following information is shown:

  • Tour name
  • Date range
  • Available seats for booking

Booking a Tour​

When the user clicks on the Book button for a tour, they are redirected to the Tour View Details page.

Available Options​

On this page, users can:

  • Select travellers
  • Choose accommodation (if available)
  • Select add-ons / supplements
  • Enter traveler information with valid and complete details
Important

Only the passenger types enabled for the tour are visible. Similarly, only the hotels and supplements added to the tour appear in the Accommodation and Add-ons sections.

Step-by-Step Booking Flow​

The booking process follows a structured step-by-step flow:

Step 1: Passenger Selection​

Select the number and type of passengers for the tour.

Step 2: Accommodation Selection​

Opens after clicking Next on the passenger selection step.

Choose your preferred accommodation from available options.

Step 3: Add-ons / Supplements​

Opens after clicking Next on the accommodation step.

Select any additional services or supplements.

Step 4: Traveler Information​

Enter complete and valid details for all travelers.

Navigation Options​

  • Next Button: Move forward to the next step
  • Change Option: Go back and modify previously selected values
  • Back Button: Return to the previous step

Summary & Confirmation​

Summary Section​

On the left side of the screen, the Summary section displays:

  • All selected items
  • A detailed cost breakdown
  • The total booking cost

Final Confirmation​

After reviewing and finalizing the details:

  1. Verify all information in the summary
  2. Review the total cost breakdown
  3. Click on Confirm Booking to complete the process

Success

Once confirmed, the booking is successfully created and can be viewed in the Admin Panel.

Important Notes​

  • All required fields must be filled before proceeding
  • Selected values can be modified at any time using the Change option
  • The booking summary updates automatically as selections are made
  • Only enabled tour features will be visible to users

Troubleshooting​

Search parameters not showing?

  • Verify parameters are enabled in Admin Portal
  • Check if the widget configuration is saved
  • Refresh the widget page

Cannot proceed to next step?

  • Ensure all required fields are completed
  • Check for validation errors
  • Verify passenger count matches tour availability

Booking not appearing in Admin Panel?

  • Confirm the booking was successfully completed
  • Check the date range filter in Admin Panel
  • Verify user permissions

For additional support or questions, contact the technical team.
